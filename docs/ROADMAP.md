# Дорожная карта QuiTa

## Статус: MVP завершён

### Что сделано

- ✅ Быстрый ввод через горячую клавишу (⌘⇧Q на macOS, Win+Alt+Q на Windows,
  Ctrl+Alt+Q на Linux)
- ✅ Задачи и подзадачи (один уровень вложенности)
- ✅ Автоматическое завершение подзадач при завершении родителя
- ✅ Точечное восстановление подзадач при повторном открытии родителя
- ✅ Сроки (календарные даты) с подсветкой просроченных
- ✅ Поиск по названию с контекстом родителя
- ✅ Мягкое удаление с каскадом и восстановлением
- ✅ Темы: светлая, тёмная, системная
- ✅ Экспорт/импорт полного состояния в JSON (YAML и XML отменены: уязвимые парсеры)
- ✅ Трей-режим
- ✅ Локальное хранение в SQLite
- ✅ Полное покрытие тестами (Rust + TypeScript)
- ✅ Статус «Не актуальная» — контекст-меню и `⌘D`/`Ctrl+D`; красная
  приглушённая строка с крестиком, статус и влияние «как у закрытой»
  (список, поиск, счётчики, таймер автоудаления); каскад по подзадачам
  зеркально завершению

## Принципы развития

1. **Не ломать основной сценарий** — горячая клавиша → ввод → Enter → назад к работе
2. **Локальное хранение по умолчанию** — приватность прежде всего
3. **Минимим зависимостей** — только необходимое
4. **Тесты для нового функционала** — покрытие не ниже текущего
5. **Обратная совместимость данных** — миграции без потери данных

## Известные ограничения MVP

- Нет регистрации и аккаунтов
- Нет облачной синхронизации
- Нет веб-версии
- Нет повторяющихся задач
- Нет вложенности более одного уровня
- Нет тегов и проектов
- Нет системных уведомлений
