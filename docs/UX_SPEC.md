# Спецификация интерфейса QuiTa

## Окно приложения

- **Размер**: 420×600 px
- **Минимальный размер**: 380×480 px
- **Изменяемый размер**: да
- **Разворот**: двойной клик по логотипу разворачивает окно на всю высоту рабочей области, повторный клик возвращает 420×600
- **Заголовок окна**: скрыт (`hiddenTitle: true`)
- **Декорации**: стандартные
- **Начальное состояние**: скрытое (`visible: false`)

## Структура окна

### Верхняя панель
- Кнопка настроек (иконка шестерёнки)
- Кнопка переключения темы (опционально)

### Поиск
- Поле ввода с плейсхолдером «Поиск…»
- Очистка по крестику
- Результаты отображаются сразу при вводе

### Список задач
- Корневые задачи с подзадачими
- Новые задачи появляются сверху
- Подзадачи отображаются с отступом

### Пустое состояние
- **Нет задач**: «Пока всё чисто»
- **Поиск не дал результатов**: «Ничего не найдено»

### Поле добавления
- Расположено внизу окна
- Плейсхолдер: «Новая задача…»
- Автофокус при открытии окна по горячей клавише

## Правила быстрого ввода

### Создание задачи
1. Пользователь вводит текст в поле добавления
2. Нажимает Enter
3. Задача создаётся и появляется в списке
4. Поле очищается и остаётся в фокусе
5. Пользователь может сразу вводить следующую задачу

### Защита от дублей
- Повторное нажатие Enter при пустом поле не создаёт задачу
- Пустые и состоящие только из пробелов названия отклоняются

### Обработка ошибок
- При ошибке создания текст не теряется
- Сообщение об ошибке отображается в виде тоста

### Тайминг тостов
- Ошибка операции с задачей и итог импорта — 6 секунд
- Успешный экспорт — 5 секунд
- Ошибка экспорта или импорта — без таймера, до начала следующей операции

## Inline-редактирование

### Вход в режим редактирования
- Двойной клик по названию задачи
- Контекстное меню не содержит пункта редактирования: переименование доступно только двойным кликом

### Режим редактирования
- Поле ввода заменяет текст задачи
- Курсор в конце текста
- Выделен весь текст (опционально)

### Сохранение
- **Enter** — сохранить изменения
- Пустое название не сохраняется (откат к исходному)

### Отмена
- **Escape** — отменить редактирование
- Клик вне поля — отменить редактирование

## Удаление задач

### Контекстное меню задачи
Пунктов «Редактировать», «Установить срок» и «Добавить подзадачу» в нём нет:
у каждого из этих действий есть своя кнопка в строке. Состав меню:

| Пункт | Когда доступен |
|-------|---------------|
| «Удалять завершённые через N дней» / «Автоудаление: N дн.» | всегда |
| «Переместить вверх» | корневые задачи |
| «Переместить вниз» | корневые задачи |
| «Удалить» | всегда |

Между группами стоят разделители, «Удалить» помечен как опасный пункт.

### Подтверждение
- Диалог подтверждения показывается при любом удалении
- Текст предупреждает о каскадном удалении, только если у задачи есть подзадачи
- Кнопки: «Удалить» / «Отмена»
- **Enter** подтверждает, **Escape** диалог не закрывает — отмена только кнопкой или кликом по фону

### Каскадное удаление
- Удаление родителя удаляет все его подзадачи
- Операция атомарна (одна транзакция)
- Удалённые задачи попадают в корзину (мягкое удаление)

### Восстановление
- Доступно на отдельной вкладке настроек «Корзина»
- Восстановление корневой задачи возвращает и все её мягко удалённые подзадачи
- Подзадача, восстановленная отдельно, когда её родитель ещё в корзине, становится корневой
- Там же — необратимое удаление задачи и очистка корзины

## Подзадачи

### Отображение
- Подзадачи отображаются под родителем с отступом
- Прогресс отображается как «выполнено/всего» (например, «2/4»)
- Клик по треугольнику раскрывает/сворачивает список подзадач

### Создание
- Кнопка «+» в строке (у корневой задачи)
- Подзадачу можно добавить и к завершённой корневой задаче — строка читается как «частично выполнено»
- К подзадаче подзадачи добавить нельзя

### Завершение
- Завершение родителя завершает все незавершённые подзадачи
- Повторное открытие родителя восстанавливает только автоматически завершённые подзадачи
- Ручное завершение подзадачи не затрагивается

## Сроки

### Установка
- Через кнопку с датой в строке задачи
- Всплывающая панель: поле `input[type=date]` со степпером «− / +», быстрые кнопки «Сегодня» и «Завтра», кнопка очистки
- Дата в формате YYYY-MM-DD

### Отображение
- Дата отображается справа от названия
- Просроченные задачи подсвечиваются красным
- Сегодняшние даты подсвечиваются жёлтым (опционально)

### Валидация
- Дата должна быть в формате YYYY-MM-DD
- Невозможные даты (2025-02-30) отклоняются
- Срок родителя не влияет на подзадачи

## Поиск

### Поведение
- Поиск выполняется по мере ввода
- Результаты включают корневые задачи и подзадачи
- Для подзадач отображается контекст родителя

### Пустые состояния
- Нет результатов: «Ничего не найдено»
- Пустой запрос: отображается обычный список

### Экранирование
- Символы `%` и `_` экранируются в поисковом запросе
- Поиск нечувствителен к регистру

## Темы

### Варианты
- **Светлая** — светлый фон, тёмный текст
- **Тёмная** — тёмный фон, светлый текст
- **Системная** — следует за системной темой

### Переключение
- Через Настройки → Внешний вид
- Выбор сохраняется в базе данных
- Применяется мгновенно

## Доступность

### Focus rings
- Все интерактивные элементы имеют видимый focus ring
- Focus ring контрастный и заметный

### ARIA-роли
- Кнопки имеют `role="button"` и `aria-label`
- Чекбоксы имеют `role="checkbox"` и `aria-checked`
- Диалог подтверждения удаления имеет `role="alertdialog"`, окно «О программе» — `role="dialog"`; оба с `aria-modal="true"`
- Тосты имеют `role="alert"` или `role="status"`

### Клавиатурная навигация
- **Tab** — переход между элементами
- **Enter** — активация элемента, подтверждение удаления
- **Escape** — отмена редактирования, закрытие контекстного меню, поиска и настроек; диалоги подтверждения удаления и «О программе» им не закрываются
- **Пробел** — переключение чекбокса
- **Стрелки вверх/вниз** — навигация по списку (опционально)

## Трей

### Иконка
- Отображается в системном трее / меню-баре
- Левый клик показывает окно, но не скрывает его
- Правый клик открывает меню

### Меню
- «Open QuiTa / Открыть QuiTa» — показать окно
- «About / О программе» — окно о программе
- Разделитель
- «Quit / Выйти» — завершить приложение

Подписи двуязычные: меню строит система до того, как известен язык интерфейса.

### Закрытие окна
- Крестик скрывает окно, а не закрывает приложение
- Приложение продолжает работать в трее
