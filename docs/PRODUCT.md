# Продуктовая документация QuiTa

## Проблема

Пользователи постоянно отвлекаются на мысли о задачах во время работы. Нужно быстро зафиксировать задачу и вернуться к текущей работе без потери фокуса. Существующие решения слишком тяжёлые, требуют регистрации, работают через браузер или имеют слишком сложный интерфейс.

## Пользователь

Разработчики, дизайнеры, писатели и другие специалисты, которые:
- Работают за компьютером и часто переключаются между задачами
- Хотят быстро записать мысль, не отвлекаясь на интерфейс
- Ценят приватность и локальное хранение данных
- Используют macOS, Windows или Linux

## Основной сценарий

1. Пользователь работает в другом приложении
2. Нажимает горячую клавишу (Cmd+Shift+Q / Ctrl+Shift+Q)
3. Окно QuiTa появляется, курсор уже в поле ввода
4. Пользователь вводит текст задачи и нажимает Enter
5. Окно скрывается, пользователь возвращается к работе

## Принципы

### Мгновенный отклик
- Горячая клавиша работает из любого приложения
- Окно открывается мгновенно, поле ввода уже в фокусе
- Нет загрузочных экранов и анимаций, мешающих работе

### Минимум действий
- Одно нажатие клавиши для открытия
- Одно нажатие Enter для создания задачи
- Нет обязательных полей, кроме названия
- Удаление и восстановление в два клика

### Низкий визуальный шум
- Компактное окно 420×600
- Минималистичный дизайн без лишних элементов
- Пустые состояния с дружелюбными сообщениями
- Тёмная тема для работы вечером

### Надёжное локальное хранение
- Все данные в SQLite на локальном диске
- Нет зависимости от сети и облака
- Мягкое удаление с возможностью восстановления
- Транзакционные операции для целостности данных

## Границы MVP

### Входит
- Задачи и подзадачи (один уровень)
- Быстрый ввод через горячую клавишу
- Сроки (календарная дата)
- Поиск по названию
- Мягкое удаление и восстановление
- Темы оформления
- Экспорт и импорт полного состояния (задачи с иерархией, корзина, вкладки,
  настройки) в JSON
- Трей-режим

### Не входит
- Регистрация и аккаунты
- Облачная синхронизация
- Веб-версия
- Проекты, папки, теги
- Вложенность более одного уровня
- Повторяющиеся задачи
- Телеметрия
- Импорт данных

## Критерии приёмки

### Производительность
- Открытие окна по горячей клавише ≤ 300 мс
- Создание задачи ≤ 50 мс
- Поиск ≤ 100 мс на базе до 10 000 задач

### Надёжность
- Потеря данных невозможна при корректном закрытии
- Мягкое удаление защищает от случайной потери
- Транзакции обеспечивают целостность при каскадных операциях

### Удобство
- Пользователь может создать задачу за 3 секунды от нажатия клавиши
- Все основные операции доступны с клавиатуры
- Окно не перекрывает рабочую область полностью

### Приватность
- Нет сетевых запросов
- Нет телеметрии
- Данные хранятся только локально
