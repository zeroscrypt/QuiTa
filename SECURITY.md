# Безопасность QuiTa

## Модель безопасности

QuiTa — полностью локальное приложение. Все данные хранятся на устройстве пользователя и никуда не передаются.

### Принципы

- **Сеть только для проверки обновления** — единственный сетевой запрос уходит в GitHub за списком релизов; ни данные задач, ни телеметрия никуда не отправляются
- **Нет телеметрии** — никакой информации о использовании не собирается
- **Нет аккаунтов** — нет регистрации и авторизации
- **Локальное хранение** — данные только в SQLite на локальном диске

## Хранение данных

### Расположение

База данных хранится в каталоге приложения Tauri:

| Платформа | Путь |
|-----------|------|
| macOS | `~/Library/Application Support/com.quita.app/quita.db` |
| Windows | `%APPDATA%\com.quita.app\quita.db` |
| Linux | `~/.local/share/com.quita.app/quita.db` |

### Защита

- Доступ к базе данных только у приложения
- Стандартные права доступа файловой системы
- Режим WAL для целостности данных
- Внешние ключи включены

## SQL-инъекции

Все SQL-запросы используют параметризованные запросы:

```rust
conn.query_row(
    "SELECT * FROM tasks WHERE id = ?1",
    [id],
    row_to_task
)
```

Пользовательский ввод никогда не подставляется в SQL напрямую.

## Content Security Policy

CSP задан в `tauri.conf.json` и ограничивает загрузку кода локальным:

```
default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline';
img-src 'self' data: asset: http://asset.localhost;
font-src 'self' data:; connect-src 'self' ipc: http://ipc.localhost
```

`script-src 'self'` запрещает и внешние скрипты, и `unsafe-eval`.

## Tauri Capabilities

Приложение использует минимальный набор разрешений (`src-tauri/capabilities/default.json`):

| Разрешение | Назначение |
|------------|------------|
| `core:default` | Базовые разрешения Tauri |
| `dialog:allow-save` | Сохранение файлов (экспорт) |
| `dialog:allow-open` | Открытие файлов (импорт) |
| `updater:default` | Проверка и установка обновления |
| `process:allow-restart` | Перезапуск после установленного обновления |
| `opener:allow-open-url` | Ссылка на репозиторий в «О программе», ограничена одним URL |

Глобальная горячая клавиша регистрируется из Rust (`tauri-plugin-global-shortcut`), поэтому webview не нуждается в `global-shortcut:*`. Плагины файловой системы, shell и HTTP не выданы.

## Уязвимости

### Как сообщить

Если вы нашли уязвимость, пожалуйста:

1. **Не публикуйте** информацию об уязвимости публично
2. Напишите на почту или создайте приватный issue в GitHub
3. Опишите шаги для воспроизведения
4. Укажите потенциальное воздействие

### Что мы делаем

- Рассматриваем все сообщения
- Исправляем критические уязвимости в первую очередь
- Обновляем документацию при необходимости

## Зависимости

### Мониторинг

- Зависимости Rust проверяются `cargo audit`
- Зависимости Node.js проверяются `pnpm audit`
- Обновления зависимостей применяются регулярно

### Известные ограничения

- **rusqlite bundled** — версия SQLite зафиксирована, обновляется вместе с rusqlite
- **Tauri 2** — следим за обновлениями безопасности

## Рекомендации для пользователей

- Регулярно делайте резервную копию базы данных
- Не храните конфиденциальную информацию в задачах (пароли, финансовые данные)
