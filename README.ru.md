## Что это

Каждый менеджер задач предлагает **планировать**. QuiTa предлагает **записывать**.

Мысль возникает, когда вы уже три часа в чём-то другом. Любой полноценный
планировщик превращает это в трение: найти окно, найти список, выбрать проект,
подумать про срок, написать описание. Мысль исчезает, а вы оказываетесь в
другом приложении.

```
   ⌘⇧Q             окно появилось, курсор уже в поле ввода
   «позвонить поставщику насчёт счёта»
   ⏎                сохранено, поле очищено, курсор остался
   «отправить счёт поставщику»
   ⏎                снова сохранено — и так сколько угодно раз
   +                у первой задачи — поле подзадач, ведёт себя так же
   ────
   ~0,4 с на задачу — и вы снова в редакторе
```

Задача сохранена, курсор остался на месте. Окно не прячется само — закрыть его
можно тогда, когда вы закончили, и не раньше. Это и есть весь продукт. Всё
остальное — вкладки, подзадачи, сроки, перетаскивание — существует, чтобы
запись **потом** оказалась полезной, а не для того, чтобы замедлить момент
ввода.

Никаких аккаунтов. Никакого облака. Никакой телеметрии. База — один файл
SQLite на вашем диске.

## Установка

- [x] **Готовая сборка одной командой** — macOS и Linux
- [x] **Готовая сборка одной командой** — Windows
- [x] **Скачать файл вручную** — `.dmg`, `.msi`, `.AppImage`, `.deb`
- [x] **Сборка из исходников**
- [x] **Проверка целостности** — SHA-256 каждого файла в `SHA256SUMS`

### macOS и Linux — одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/zeroscrypt/QuiTa/main/scripts/install.sh | bash
```

Скрипт определяет систему и процессор, скачивает нужный файл, сверяет его
SHA-256 с опубликованной суммой и только потом распаковывает. Ничего не
запускается до проверки.

### Windows — одной командой

```powershell
irm https://raw.githubusercontent.com/zeroscrypt/QuiTa/main/scripts/install.ps1 | iex
```

Запускать в PowerShell **от имени администратора** — установщик ставится для
всех пользователей, и без прав Windows отказывает молча, кодом `1603`.
Скрипт проверяет это заранее и говорит, если прав не хватает.

### Скачать вручную

[**Releases**](https://github.com/zeroscrypt/QuiTa/releases/latest) →
выберите файл под свою систему:

| Платформа | Файл |
|-----------|------|
| macOS (Apple Silicon, Intel) | `QuiTa_<версия>_aarch64.dmg` · `QuiTa_<версия>_x64.dmg` |
| Windows | `QuiTa_<версия>_x64-setup.exe` · `QuiTa_<версия>_x64_en-US.msi` |
| Linux | `QuiTa_<версия>_amd64.AppImage` · `QuiTa_<версия>_amd64.deb` |

### Из исходников

**Нужно:** Node.js 22+, pnpm 12+, Rust stable. На Linux дополнительно
`libwebkit2gtk-4.1-dev`, `libappindicator3-dev`, `librsvg2-dev`, `patchelf`.

```bash
git clone https://github.com/zeroscrypt/QuiTa.git
cd QuiTa
pnpm install
pnpm tauri dev          # запуск с горячей перезагрузкой
pnpm tauri build        # сборка установщиков
```

`pnpm tauri build` создаёт `.app` + `.dmg` на macOS, `.msi` + `.exe` на
Windows, `.AppImage` + `.deb` на Linux.

> При сборке подписывать обновления не нужно: артефакты для автообновлений
> собираются только в CI, ключ подписи лежит в секретах GitHub и в вашей
> локальной сборке не требуется.

## Возможности

- [x] **Вкладки как проекты** — создание, переименование двойным кликом, порядок перетаскиванием, автоцвет из палитры. Удаление вкладки спрашивает подтверждение и отменяется одним нажатием: сперва исчезает только вкладка, задачи ждут конца десяти секунд и уходят в корзину, если никто не передумал.
- [x] **Подзадачи** — ровно один уровень вложенности, и точка.
- [x] **Сроки** — календарные даты без сдвига часовых поясов, просроченные подсвечиваются, чипы «сегодня / завтра».
- [x] **Комментарии** — автосохранение, открываются кнопкой у строки задачи.
- [x] **Шторм-ввод** — поле не закрывается после `Enter`, курсор остаётся на месте.
- [x] **Перетаскивание** — три зоны, без таймеров и удержаний.
- [x] **Корзина** — мягкое каскадное удаление, предел в 200 задач и автоочистка по сроку.
- [x] **Поиск** — без задержки, сохраняет контекст родителя.
- [x] **Тёмная и светлая тема** — следует за системой или фиксируется вручную.
- [x] **Русский и English** — переключается в настройках, применяется сразу.
- [x] **Живёт в трее** — закрытие окна прячет приложение, а не завершает.
- [x] **Горячая клавиша** — `⌘⇧Q` на macOS, `Win+Alt+Q` на Windows и `Ctrl+Alt+Q` на Linux открывают окно с фокусом в поле ввода.
- [x] **Экспорт и импорт** — весь снимок приложения в JSON.
- [x] **Обновление из приложения** — зелёная плашка над вкладками: «Доступна новая версия».
- [x] **Окно растягивается** — двойной клик по лого разворачивает на всю высоту рабочей области экрана и расширяет в 1,6 раза по ширине. Панель задач и строка меню не перекрывают окно, и оно всегда остаётся целиком на экране.
- [x] **Не актуальная** — пометка без удаления: красная приглушённая строка с крестиком, статус во всех списках «как у закрытой». Пункт меню и `⌘D`/`Ctrl+D` для последней нажатой задачи.
- [x] **Найти задачу по сроку** — просроченные выделены отдельным цветом.
- [x] **Клавиатура** — `Enter` сохраняет, `Esc` отменяет, `Tab` не теряет позицию.

## Как это работает

### Шторм

```
   ┌──────────────────────────────────────────┐
   │ Написать релизные заметки                 │  ⏎
   │ Отправить счёт поставщику                │  ⏎
   │ Забрать посылку                          │  ⏎
   └──────────────────────────────────────────┘
```

`Enter` создаёт задачу, очищает поле и оставляет курсор на месте. Нажали `+`
у корневой задачи — поле подзадач ведёт себя точно так же.

### Переключение вкладок

`⌘1`…`⌘9` на macOS, `Ctrl+1`…`Ctrl+9` на Windows и Linux — то же сочетание,
что в любом приложении с вкладками. Цифра соответствует порядку на полосе
вкладок, поэтому после перетаскивания вкладок номера меняются вместе с ними.

Курсор после переключения всегда оказывается в поле ввода: можно сразу
набирать задачу в только что выбранную вкладку. Цифра за пределами числа
вкладок ничего не делает, а диалоги на время открытия сочетание забирают
себе.

Клик мышью по вкладке ведёт себя так же: поле ввода сразу готово к
набору.

### Остальные сочетания

| Сочетание | Что делает |
|-----------|------------|
| `⌘T` / `Ctrl+T` | новая вкладка — открывает то же поле имени, что и кнопка «+» |
| `⌘F` / `Ctrl+F` | курсор в поле поиска |
| `⌘S` / `Ctrl+S` | настройки |
| `⌘D` / `Ctrl+D` | «не актуальная» для последней нажатой задачи: красная приглушённая строка с крестиком, статус как у закрытой |
| `⌘1`…`⌘9` / `Ctrl+1`…`Ctrl+9` | переключение вкладок (выше) |

Все три работают с той же модификацией, что и цифры, и точно так же уступают
клавиатуру открытому диалогу. Полный список сочетаний — в настройках, в
секции «Горячая клавиша»: там подписи расставлены по вашей клавиатуре. `⌘T` не создаёт безымянную вкладку за спиной у
человека: он открывает то же поле, что и кнопка, — с названием, ради которого
вкладка и нужна.

### Escape

`Esc` закрывает верхний открытый слой — по одному слою на нажатие: дата,
комментарий, меню, подтверждение удаления, панель настроек. Раньше каждый
из них слушал клавишу сам по себе, и одно нажатие закрывало их все сразу,
а открытый диалог подтверждения Escape не закрывал вовсе.

Когда последний слой закрыт, курсор оказывается в поле ввода. Если открыто
ничего, `Esc` очищает поле — как и раньше.

### Три зоны перетаскивания

```
   ┌─────────────────────────────────────────┐
   │ ░░░░░░░░░ вставить выше ░░░░░░░░░░░░░░░ │  верхняя четверть
   │ ▓▓▓▓▓ отпустить → станет подзадачей ▓▓▓ │  средняя половина
   │ ░░░░░░░░░ вставить ниже ░░░░░░░░░░░░░░░ │  нижняя четверть
   └─────────────────────────────────────────┘
```

- [x] **Без удержания и таймеров.** Место вставки видно *до* отпускания.
- [x] **Последняя позиция — настоящая.** Пустое место под списком значит «вставить в конец».
- [x] **Перетаскиваются и задачи, и вкладки.** Задача на вкладку — перенос вместе с подзадачами.
- [x] **Циклы невозможны** — задачу нельзя вложить в собственное поддерево.

### Правила завершения

- [x] **Завершение родителя либо завершает подзадачи, либо не трогает их** — переключатель в настройках.
- [x] **Повторное открытие восстанавливает ровно те подзадачи, которые закрыл каскад**, и никогда не трогает закрытые вами.
- [x] **Подзадача никогда не трогает родителя.** Сняли галочку — задача осталась закрытой и стала ◐ частично выполненной.

### Корзина

- [x] **Задача уходит в корзину вместе с подзадачами.** Родитель без детей остаться не может: они повисли бы в списках, где их не видно.
- [x] **Корзина держит 200 задач** — число настраивается, ноль выключает правило. Место кончилось — новая задача вытесняет самую старую: она уходит навсегда вместе с подзадачами, остальные сдвигаются. Предел держится на всех путях в корзину: ручное удаление, таймер завершённых, удаление вкладки — и о вытесненном сообщает тост на каждом из них.
- [x] **Срок хранения настраивается отдельно** — по умолчанию выключен, потому что удалять без спроса нельзя. Включите — и пролежавшее указанное число дней дерево уйдёт при следующем запуске. Отсчёт от последнего удаления в дереве: подзадача, выброшенная позже родителя, получит свой полный срок.
- [x] **О вытеснении приложение говорит вслух.** Задача исчезла не по вашей воле, поэтому тост называет ту, которая ушла.
- [x] **В шапке корзины настоящее число**, а не то, что поместилось на экран; остальное достаётся кнопкой «Показать ещё».

## Данные

- [x] **Один файл SQLite на устройстве.**
- [x] **Ни одного сетевого соединения** — кроме проверки обновления.
- [x] **Экспорт = снимок всего состояния**: задачи с иерархией, корзина, вкладки, настройки.
- [x] **Импорт ничего не удаляет** — только добавляет и обновляет записи по `id`.
- [x] **Битая иерархия чинится**: подзадача без родителя становится корневой, а не исчезает.

```json
{
  "version": 2,
  "exportedAt": "2026-10-14T09:41:00Z",
  "tabs": [{ "id": "…", "name": "Работа", "color": "#4c6fff", "sortOrder": 0 }],
  "settings": { "theme": "dark", "language": "ru", "newestFirst": true },
  "tasks": [{ "id": "…", "title": "Позвонить поставщику", "parentId": null, "tabId": "…" }]
}
```

Формат один — JSON: он читается любым инструментом и не содержит парсера,
который можно сломать чужим файлом. Файлы старой версии 1 импортируются как есть.

| Платформа | Путь к базе |
|-----------|-------------|
| macOS | `~/Library/Application Support/com.quita.app/quita.db` |
| Windows | `%APPDATA%\com.quita.app\quita.db` |
| Linux | `~/.local/share/com.quita.app/quita.db` |

> Папка `Application Support` не синхронизируется iCloud Drive. Если нужна
> одна база на двух Apple-устройствах — перенесите файл вручную или пользуйтесь
> экспортом: iCloud синхронизирует файлы целиком, и два открытых приложения
> перезапишут базу друг друга.

## Разработка

### Стек

| Слой | Выбор | Зачем |
|------|-------|-------|
| Оболочка | **Tauri 2** | Несколько мегабайт вместо сотен; нативные окно, трей и горячие клавиши. |
| Интерфейс | **Svelte 5** (runes) | Точечная реактивность — приложение почти целиком состоит из списков. |
| Язык | **TypeScript** | Строгие типы и общий контракт с Rust. |
| Логика | **Rust** | Правила завершения, каскады, миграции — чистые функции под тестами. |
| Хранилище | **SQLite** (`rusqlite`, bundled) | Один файл, без сервера и без нативных зависимостей. |

```
frontend (Svelte 5 + TS)  ──invoke──▶  Tauri-команды  ──▶  repository (rusqlite)
        │                                                          │
        └────────────────────  события  ◀────────────────────────────┘
```

Бизнес-правила живут в `src-tauri/src/domain/rules.rs` как чистая функция,
возвращающая план действий, а репозиторий только применяет его. Поэтому всё
интересное поведение тестируется без окна.

### Команды

| Команда | Что делает |
|---------|-----------|
| `pnpm tauri dev` | Запуск с горячей перезагрузкой |
| `pnpm tauri build` | Установщики под текущую платформу |
| `pnpm check` | Типы Svelte и TypeScript |
| `pnpm test` | 176 модульных тестов |
| `cargo test --manifest-path src-tauri/Cargo.toml` | 166 Rust-тестов (47 модульных + 115 интеграционных на настоящей базе + 4 на документацию) |
| `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets` | Линты, ошибки как предупреждения |
| `cargo audit` | Уязвимости в зависимостях |

### Сколько это стоит

| | |
|---|---|
| Размер приложения | 17,9 МБ — практически целиком бинарь |
| Размер `.dmg` | 5,8 МБ — то же самое в сжатом виде |
| Размер базы | 618 байт на задачу |
| Запрос к базе | 1,5 мс на поиск, 11 мс на список из тысячи |

Цифры измерены, а не прикинуты: база на 1000 задач после уплотнения занимает
604 КБ. Запросы замерены на той же базе — полный список тысячи задач занимает
11 мс, поэтому на реальной базе в десятки задач всё на порядки быстрее.

Размер файла базы зависит от истории, а не от текущего числа задач: SQLite не
отдаёт место назад, пока его не уплотнить. Кнопка «Уплотнить базу» в настройках
делает это вручную.
